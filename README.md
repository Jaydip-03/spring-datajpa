\# Spring Data JPA 🚀



A hands-on learning repository for understanding and practicing \*\*Spring Data JPA, JPA, Hibernate, and database integration with Java\*\*.



This repository contains multiple small projects, practice programs, experiments, and implementations created while learning Spring Data JPA and applying its concepts to real-world applications.



\---



\## 📚 What I'm Learning



This repository covers:



\- Spring Data JPA fundamentals

\- JPA \& Hibernate

\- Entity mapping

\- Repository interfaces

\- `JpaRepository`

\- CRUD operations

\- Derived Query Methods

\- Custom queries using `@Query`

\- Named Queries

\- `Optional`

\- Pagination

\- Sorting

\- Entity Relationships

&#x20; - One-to-One

&#x20; - One-to-Many

&#x20; - Many-to-One

\- PostgreSQL integration

\- MySQL integration

\- H2 Database

\- Spring MVC integration

\- JSP integration

\- Form handling

\- Database-driven applications
